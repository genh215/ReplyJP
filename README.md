# ReplyJP

受信した日本語メールへの返信文例を、ローカル環境で生成する Windows アプリです。メール本文を外部へ送信することはなく、メール送信機能も備えていません。

## 動作環境

- **OS**: 64ビット版 Windows 10 / 11
- **GPU**: Vulkan 対応 GPU（**VRAM 8GB 以上**）
  - CPU のみでは動作しません。
  - 実際の VRAM 使用量は GPU や実行環境によって異なります。
- **その他**: 初回セットアップ時のみ、インターネット接続と十分なディスク空き容量が必要です。モデル（約 6.72 GB）および llama.cpp は配布 ZIP に含まれていないため、アプリ内からダウンロードします。

## 使い方

1. 配布 ZIP を展開し、`ReplyJP.exe` を起動します。
2. llama.cpp の「ダウンロード」をクリックし、完了後にモデルの「ダウンロード（6.72GB）」をクリックします（取得済みの場合は不要です）。
3. 「受信メール」欄に本文を貼り付けます。相手の所属・名前、自分の名前、返信に含めたい内容は任意で入力できます（名前や所属が空欄の場合、受信メールから自動推定を試みます）。
4. 「返信文生成」をクリックし、生成された宛名・本文・署名を確認します。必要に応じて編集し、「返信文コピー」でコピーしてください。

> **補足**
> - 「入力クリア」を押すと入力欄のみが空になり、生成済みの返信文はそのまま残ります。
> - 一度読み込んだモデルは、アプリを閉じるまでメモリ上に保持されます。

## モデルと推論エンジン

- **使用モデル**: [Unsloth Gemma 4 12B IT QAT（UD-Q4_K_XL）](https://huggingface.co/unsloth/gemma-4-12B-it-qat-GGUF)
- **推論エンジン**: [llama.cpp](https://github.com/ggml-org/llama.cpp)
- **生成設定**: コンテキスト長は 32,768 トークン（入力・プロンプト・思考・返信を含む）です。思考機能（Thinking）が有効になっており、思考トークンの上限は 1,024 トークンです。

### 更新とネットワーク設定

- llama.cpp の「更新確認」をクリックすると、新しいバージョンがある場合にダウンロードします。起動時の自動ダウンロードや自動更新確認は行いません。
- ダウンロードおよび更新確認には、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY` などの環境変数が使用されます。Windows のプロキシ設定や追加の証明書は参照しません。
